# Актуальная схема развёртывания

[English](README.md) · [Главная страница](../README.ru.md) · [Права и ограничения](../docs/ru/LEGAL.md)

Обезличенная версия кода действующей установки, подготовленная в сентябре 2026 года. Это исходники и инструкция, а не образ чужого сервера. Здесь нет учётных данных, личной медиатеки, журналов запросов или настроенных источников контента.

## Подробные руководства

- [Как всё устроено, подключение, автозапуск и диагностика](docs/OPERATIONS.ru.md).
- [Что можно публиковать, лицензии и защита личных данных](docs/PUBLICATION.ru.md).

Ниже — последовательность установки; руководства объясняют причины настроек и ожидаемый результат каждого этапа.

## Зачем это нужно

Управлять собственной домашней медиатекой из личного чата Telegram: передавать разрешённые `.torrent` и magnet-ссылки в Transmission, видеть прогресс, ставить загрузки на паузу, выбирать сезоны и просматривать имеющиеся файлы. Можно подключить распознавание названий и поиск по собственным разрешённым источникам. Воспроизведение происходит в Plex или другом плеере, а не в Telegram.

Примеры подходящих материалов: собственные записи, материалы с явным разрешением на скачивание и раздачу, произведения с проверенной свободной лицензией. Слово «торрент» описывает способ передачи и само по себе не подтверждает права на конкретный файл. При скачивании клиент может одновременно отдавать части другим участникам.

## Где что работает

| Компонент | Размещение | Задача |
|---|---|---|
| `bot/` | Linux-сервер или тот же Mac | Telegram, доступ пользователей, поиск, очередь команд, карточки |
| `mac_agent/` | Mac с медиадиском | Проверка диска, локальный Transmission RPC, файлы, библиотека |
| Transmission | Mac | Передача файлов; параметры отдачи задаёт оператор |
| Внешний диск | Mac | Отдельные папки Movies, TV и Downloads/Incomplete |
| Prowlarr, необязательно | Рядом с ботом | Поиск по источникам, которые оператор подключает самостоятельно |
| Plex, необязательно | Mac | Библиотека и воспроизведение; лицензия и подписка отдельные |
| SSH-туннель | Mac → сервер | Доступ бота к агенту через loopback, без публичного порта агента |

Один Mac достаточен для первого запуска. На отдельном сервере не нужна копия медиатеки. Исходящие обращения к Telegram и включённым внешним API требуют сети. Поиск и передача будут зависеть от доступности выбранных сервисов.

## Отличия от установленного частного кода

Сохранены механизм поиска, повторы, независимые карточки, очередь, прогноз прогресса и управление медиатекой. Публичный запуск использует ваши числовые Telegram ID; имена аккаунтов, телефонная привязка, названия дисков и служебные пути конкретной установки заменены общими настройками. Внешние изображения и голос выключены по умолчанию. Модель нужно выбрать явно.

Не включены авторизованные браузерные сессии, сайтоспецифичные браузерные загрузчики, средства прохождения защитных страниц, готовые индексаторы, прокси/VPN-профили и реальные поисковые выгрузки. Поэтому расширенное чтение описаний с конкретных сайтов здесь не настраивается. Основной поиск через Prowlarr работает независимо от него. Тестовые данные синтетические; названия произведений в тестах не являются каталогом для скачивания.

Корневые `bot/` и `mac_agent/` — предыдущая базовая публичная версия. Не смешивайте её файлы с этой папкой. Для описанных здесь функций запускайте команды именно из `deployment-reference`.

## 1. Подготовка

Нужны поддерживаемая macOS для агента, Python 3.11–3.13, Transmission с локальным RPC, свободное место и отдельные папки для медиатеки. На Linux нужен Python той же версии. Код использует стандартную библиотеку Python. Telegram и необязательные внешние API требуют собственных аккаунтов; их стоимость и доступность проверяйте отдельно. Старое оборудование не является гарантией поддержки или безопасности.

```sh
git clone https://github.com/Lemelson/home-media-assistant.git
cd home-media-assistant/deployment-reference
python3 --version
PYTHONPATH=.:tests python3 -m unittest discover -s tests -q
```

Тестам нужны временные локальные HTTP-порты, но не реальные ключи и скачивания. Не заменяйте системный Python и не меняйте настройки питания ради первого запуска.

## 2. Диск и Transmission на Mac

Выберите подключённый диск и узнайте его Volume UUID через `diskutil info`. Пример использует условный `/Volumes/Media`:

```sh
mkdir -p /Volumes/Media/MediaServer/Movies
mkdir -p /Volumes/Media/MediaServer/TV
mkdir -p /Volumes/Media/MediaServer/Downloads/Incomplete
diskutil info /Volumes/Media
```

Эти команды не форматируют диск. Проверьте резервную копию важных файлов. Настройте Transmission RPC на `127.0.0.1:9091` с отдельными логином и паролем; не публикуйте его в Интернете. Первое время запускайте приложение вручную. Перед передачей файла проверьте разрешение на получение **и отдачу**.

## 3. Агент на Mac

Из этой папки:

```sh
mkdir -p agent-state
chmod 700 agent-state
cp ../examples/agent.example.json agent-state/agent.json
cp ../examples/transmission-rpc.example.json agent-state/transmission-rpc.json
chmod 600 agent-state/*.json
```

Заполните свои путь диска, UUID и параметры RPC. Сгенерируйте в менеджере паролей случайный токен длиной не менее 32 символов: он будет общим для агента и бота. Не используйте пример как реальный пароль.

```sh
export AGENT_STATE_DIRECTORY="$PWD/agent-state"
python3 -m mac_agent.server
```

Агент слушает `127.0.0.1:18742`; запросы требуют токен. Оставьте терминал работающим. Не запускайте агент от root.

## 4. Бот

Создайте собственного бота через официальный BotFather. Получите свой числовой Telegram ID из экспорта Telegram либо обновления Bot API вашего бота; не передавайте токен сторонним сайтам определения ID.

```sh
cp .env.example .env
chmod 600 .env
```

В локальном `.env` заполните:

- `TELEGRAM_BOT_TOKEN` — ваш токен бота;
- `OWNER_TELEGRAM_ID` — ваш числовой ID;
- `MEMBER_TELEGRAM_ID` — необязательный второй пользователь;
- `MEDIA_AGENT_TOKEN` — тот же случайный токен;
- `MEDIA_AGENT_URL=http://127.0.0.1:18742` — если бот и агент на одном Mac;
- `STATE_DIRECTORY` — приватная папка состояния бота, отличная от состояния агента.

Пока оставьте внешние API пустыми, `ENABLE_VOICE=0`, `ENABLE_REMOTE_IMAGES=0`.

```sh
set -a
source .env
set +a
python3 -m bot
```

`.env` — исполняемый синтаксис оболочки: подключайте только собственный проверенный файл. Откройте личный чат и выполните `/start`, `/status`, `/library`. Чужой аккаунт и групповой чат должны получить отказ. Проверьте один файл, права на передачу которого вы установили самостоятельно.

## 5. Отдельный Linux-сервер

Разместите эту папку исходников на сервере под отдельным непривилегированным пользователем. Создайте его собственный `.env` и приватную папку состояния. Агент и Transmission остаются на Mac.

На Mac настройте SSH-алиас `bot-host` для своего сервера, проверьте ключ хоста и используйте отдельный ограниченный ключ. Запустите:

```sh
ssh -N -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -o ServerAliveCountMax=3 -R 127.0.0.1:18741:127.0.0.1:18742 bot-host
```

В `.env` на сервере задайте `MEDIA_AGENT_URL=http://127.0.0.1:18741`. SSH-сервер должен разрешать этот loopback reverse-forward. Не открывайте порты 18741, 18742, 9091 или Prowlarr для всего Интернета. Когда туннель недоступен, команды остаются в очереди; проверьте восстановление на своей установке.

## 6. Поиск по названию и дополнительные API

Для распознавания задайте `OPENROUTER_API_KEY` и выбранный `OPENROUTER_MODEL`; при желании — `EXA_API_KEY` для проверки названий. Установите собственный Prowlarr рядом с ботом на loopback-порту 9696, подключите самостоятельно проверенные источники и задайте `PROWLARR_API_KEY`. Сначала проверьте источник в Prowlarr, затем запрос из Telegram. Готовых логинов и перечней источников проект не поставляет.

Для голосовых запросов дополнительно включите `ENABLE_VOICE=1` и укажите подходящий `OPENROUTER_STT_MODEL`. Для постеров включите `ENABLE_REMOTE_IMAGES=1` и настройте Exa/TMDB/Serper, предварительно проверив права показа и требования провайдера. Одного наличия API-ключа для этого недостаточно. Публичный вариант по умолчанию не отправляет внешние изображения в Telegram.

Провайдеры получают запросы, а при включении соответствующих функций — голос, контекст, названия файлов и путей. История, ID, очередь, метрики и кэши сохраняются локально без шифрования приложения. [Потоки данных и удаление](../docs/ru/PRIVACY.md).

## 7. Повторный поиск

Карточка показывает первую попытку. При временной ошибке она объясняет причину, ожидание и следующую попытку. Лимит — до четырёх попыток в течение двух минут; блокировка источника может сократить их число. Повторные клики не запускают дубли. Успешные части выдачи не теряются.

Если поиск не завершился, отображаются число попыток и кнопка «Повторить поиск». Кнопка относится к своему фильму и не переключается на новый запрос. Состояние сохраняется при перезапуске; срок жизни карточки — семь суток с обновлением после неудачного цикла. Пустой успешный результат отличается от отказа источника. Раздачу может автоматически выбрать режим второго участника; включайте поиск только для источников, права на которые проверены.

## 8. Постоянный запуск и обновление

Сначала добейтесь успешного запуска в терминале. Для Linux можно адаптировать [пример systemd](examples/home-media-bot.service), подставив свои рабочую папку, пользователя, окружение и Python. На Mac можно адаптировать [пример LaunchAgent](examples/org.home-media-assistant.agent.plist). Примеры не устанавливаются сами и не содержат настроек конкретного устройства. Watchdog требует согласованных launchd labels для агента и Transmission; он не включается этой инструкцией.

Обновляйте исходники при остановленном боте, сохраняя приватные базы и настройки вне Git. Сделайте локальную резервную копию состояния, запустите тесты и проверьте `/status` после перезапуска. Откат — возврат предыдущей папки кода; совместимость базы нужно оценивать для конкретного обновления. Не включайте автоматическое обновление непроверенного Git-репозитория.

Закрытая крышка, сон, отключение диска, потеря сети и запуск после перезагрузки требуют отдельных проверок. Работа процесса не доказывает автономность сервера. Остановка бота не останавливает уже работающие передачи Transmission.

В «Загрузках» показаны свободное место, остаток всей очереди (включая паузу), место после завершения или дефицит и диапазон времени по скачанным байтам каждого фильма за последние 10 минут, включая простои. Неизвестные размеры и устаревшие данные отмечены явно. Защита может остановить загрузки до заполнения диска.
