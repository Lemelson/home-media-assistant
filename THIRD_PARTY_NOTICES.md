# Third-party software and services / Сторонние компоненты

The Python runtime code imports the standard library. This release does not bundle Python, Transmission, Plex, Prowlarr, media, fonts, logos or artwork. Install applications separately from their official distributions and preserve their licenses. Service access is subject to separate accounts, terms, costs and regional availability.

- Python: https://www.python.org/ — runtime and its own license.
- Transmission: https://transmissionbt.com/ — external BitTorrent client; its distributed components retain their licenses.
- Plex: https://www.plex.tv/ — optional proprietary media server/player; subscriptions and entitlements are separate.
- Prowlarr: https://prowlarr.com/ — optional separately installed indexer manager.
- Telegram Bot API: https://core.telegram.org/bots/api — required external messaging API.
- OpenRouter: https://openrouter.ai/ — optional model and transcription routing; selected model providers have their own conditions.
- Exa: https://exa.ai/ — optional search.
- Groq: https://groq.com/ — optional transcription.
- Serper: https://serper.dev/ — optional image search.
- TMDB: https://developer.themoviedb.org/docs/faq — optional metadata/artwork. The adapter includes the notice “This product uses the TMDB API but is not endorsed or certified by TMDB.” Operators must independently satisfy applicable attribution/logo and image-use requirements; the notice alone does not establish compliance.

Third-party names identify integrations only. No sponsorship or endorsement is implied. Fictional and real film titles in synthetic unit tests are matching fixtures, not included films or downloadable catalogues. Example URLs use reserved test domains and are not download sources.

Python использует собственную лицензию; внешние приложения и сервисы не включены в MIT-лицензию проекта. Их устанавливают и подключают отдельно с соблюдением актуальных условий. Названия в тестах — примеры для сопоставления, а не распространяемые фильмы. Изображения и логотипы не поставляются. Перед включением картинок оператор проверяет права и требования атрибуции; одного текста об использовании TMDB недостаточно.
