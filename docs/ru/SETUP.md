# Установка

[English](../en/SETUP.md) · [README](../../README.ru.md)

Начните с запуска агента и бота на одном Mac. Отдельный Linux-сервер для бота необязателен. Агент использует macOS `diskutil`, внешний диск и Transmission RPC; бот работает на macOS или Linux. Windows не поддерживается. Используйте поддерживаемую ОС и Python 3.11–3.13: работа на старом Mac в прошлом не гарантирует совместимость и безопасность. Plex устанавливается отдельно и необязателен.

## 1. Получите исходники

Клонируйте репозиторий либо скачайте **Code → Download ZIP**, распакуйте и откройте терминал в папке проекта. Не копируйте чужую рабочую среду и секреты.

```sh
python3 --version
python3 -m unittest discover -s tests -q
```

Тестам нужен временный локальный HTTP-порт. Настоящие учётные данные Telegram и источники загрузок не нужны.

## 2. Подготовьте выделенные папки

Выберите подключённый внешний диск. Ниже пример `/Volumes/Media`; замените на свой путь. Сделайте резервную копию важных данных. Форматировать диск или переносить существующие файлы не требуется.

```sh
mkdir -p /Volumes/Media/MediaServer/Movies
mkdir -p /Volumes/Media/MediaServer/TV
mkdir -p /Volumes/Media/MediaServer/Downloads/Incomplete
diskutil info /Volumes/Media
```

Сохраните **Volume UUID**, а не идентификатор раздела. Проверяются точный путь, UUID, доступность записи и папки без символических ссылок. Неверный или отсутствующий диск приостанавливает управляемую активность. Медленный USB и ExFAT могут зависать — проверьте собственное оборудование.

## 3. Настройте Transmission

Установите Transmission из официального источника. В настройках включите локальный RPC с аутентификацией, разрешите только loopback и задайте отдельные имя и пароль. RPC должен быть доступен по `http://127.0.0.1:9091/transmission/rpc`. Не пробрасывайте порт на роутере и не открывайте его в Интернет. Незавершённые файлы направьте в выделенную `Downloads/Incomplete`. Названия настроек зависят от версии Transmission.

Для первого теста оставьте приложение работающим. Проверьте поведение раздачи: BitTorrent может передавать части файлов другим участникам уже во время скачивания. Разрешение должно покрывать и это действие.

## 4. Настройте агент

В папке проекта:

```sh
mkdir -p agent-state
chmod 700 agent-state
cp examples/agent.example.json agent-state/agent.json
cp examples/transmission-rpc.example.json agent-state/transmission-rpc.json
chmod 600 agent-state/*.json
```

Локально отредактируйте оба файла: путь диска, UUID, случайный общий токен длиной минимум 32 символа и учётные данные RPC. Токен создайте менеджером паролей; такой же потребуется в `MEDIA_AGENT_TOKEN`. Не отправляйте эти файлы в issues.

Запустите агент в отдельном терминале:

```sh
export AGENT_STATE_DIRECTORY="$PWD/agent-state"
python3 -m mac_agent.server
```

Агент слушает только `127.0.0.1:18742`. Не запускайте его от root.

## 5. Настройте Telegram

Создайте бота через официальный BotFather. Получите свой числовой Telegram ID из экспорта данных Telegram или аутентифицированного обновления Bot API своего бота. Не публикуйте обновления API и не передавайте токен сайтам определения ID. Поддерживается один дополнительный участник. Групповые чаты отклоняются. После удаления ID участника из настроек и перезапуска доступ прекращается.

```sh
cp .env.example .env
chmod 600 .env
```

Заполните локально `TELEGRAM_BOT_TOKEN`, `OWNER_TELEGRAM_ID`, при необходимости `MEMBER_TELEGRAM_ID`, и `MEDIA_AGENT_TOKEN`, совпадающий с `agent.json`. Для первого запуска оставьте внешние API пустыми. На одном Mac используйте `MEDIA_AGENT_URL=http://127.0.0.1:18742`.

`.env` исполняется как shell-файл: правильно заключайте значения в кавычки и подключайте только свой доверенный файл. Во втором терминале в папке проекта:

```sh
set -a
source .env
set +a
python3 -m bot
```

В личном чате отправьте `/start`, `/status`, `/library`. Посторонний аккаунт должен получить отказ. Затем проверьте торрент, который разрешено скачивать **и раздавать**. См. [использование](USAGE.md).

## 6. Необязательные сервисы

| Настройка | Что включает |
|---|---|
| `OPENROUTER_API_KEY` и `OPENROUTER_MODEL` | Отправку запросов и ограниченного контекста в OpenRouter и выбранному провайдеру модели; нужна доступная модель со структурированным JSON |
| `EXA_API_KEY` | Поиск источников для проверки названий; используется вместе с AI |
| `PROWLARR_API_KEY` | Локальный Prowlarr на 9696; нужен AI и самостоятельно настроенные разрешённые источники |
| `ENABLE_VOICE=1` | Внешнее распознавание голоса с `GROQ_API_KEY` либо совместимой моделью OpenRouter в `OPENROUTER_STT_MODEL` |
| `ENABLE_REMOTE_IMAGES=1` | Внешние изображения, включая картинки из поиска; права и условия показа проверяет оператор |
| `TMDB_READ_ACCESS_TOKEN`, `TMDB_API_KEY`, `SERPER_API_KEY` | Дополнительные источники изображений; работают при включённых изображениях, Exa имеет приоритет |

Доступность, цены и правила хранения данных меняются: проверяйте условия у провайдера. Репозиторий не предоставляет аккаунты и подписки. Готовых индексаторов нет. Не используйте обход ограничений доступа, блокировок сервисов, подписок и географических ограничений. При включённом AI фоновая организация может отправлять имена и пути управляемых файлов внешней модели — см. [данные](PRIVACY.md).

В Plex создайте библиотеки фильмов и сериалов для `MediaServer/Movies` и `MediaServer/TV`, настройте штатное сканирование своей версии. Интеграция организации файлов может запрашивать обновление локального Plex, используя настройки вошедшего пользователя macOS. Подписки и ограничения удалённого просмотра не обходятся. Воспроизведение происходит в плеере, а не Telegram.

## Отдельный сервер бота

Агент остаётся на Mac. **С Mac** установите SSH-соединение с вашим сервером:

```sh
ssh -N -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -o ServerAliveCountMax=3 -R 127.0.0.1:18741:127.0.0.1:18742 bot-host
```

`bot-host` — ваш локально настроенный SSH alias. Проверьте ключ хоста и используйте собственный ограниченный SSH-ключ. На сервере задайте `MEDIA_AGENT_URL=http://127.0.0.1:18741`. Удалённый порт должен оставаться только loopback. Приватный SSH-ключ в репозиторий не помещайте.

## Остановка и обновления

Для первого релиза документирован запуск в терминале. Ctrl-C останавливает процесс, но Transmission может продолжать загрузки; при необходимости остановите их отдельно. Перед обновлением сохраните приватные папки состояния, замените только исходники, выполните тесты и перезапустите процессы. Не включайте автообновление из произвольной ветки Git.

`deploy/home-media-deploy` — унаследованный вспомогательный Linux-скрипт, не полный установщик. Нужны заранее созданные системный пользователь, systemd-служба, зеркало репозитория и фиксированные каталоги. Без проверки и подготовки их запускать нельзя.

Автовход, запуск после перезагрузки, сон, закрытая крышка, отключение питания и восстановление сети проверяются отдельно на вашем устройстве. Работающий Python-процесс не доказывает автономность. Этот релиз не меняет питание и не устанавливает службы автозапуска.
