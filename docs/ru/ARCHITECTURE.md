# Как и почему это работает

[English](../en/ARCHITECTURE.md)

Бот получает обновления Telegram через long polling. Числовой список допускает личный чат. Inbox сохраняет входящую работу; диалог определяет команду либо запускает необязательный поиск. SQLite хранит очередь идемпотентных команд. Отдельные обработчики передают их аутентифицированному локальному агенту Mac напрямую либо через SSH. Агент проверяет диск и принадлежность управляемого объекта, обращается к Transmission RPC и возвращает статус. Бот обновляет панель прогресса. Plex отдельно индексирует папки библиотеки.

Агент отделяет файловые операции и macOS от диалога. SQLite сохраняет очередь между перезапусками без отдельного сервера базы. ID команд и подтверждения помогают избегать повторных действий; неопределённые результаты сетевого запроса всё равно могут требовать проверки. UUID диска защищает от записи в обычную папку вместо исчезнувшего внешнего тома. Он не ремонтирует накопитель и не гарантирует целостность файловой системы.

| Код | Задача |
|---|---|
| `bot/access.py`, `bot/config.py` | Доступ и проверка конфигурации |
| `bot/inbox.py`, `bot/jobs.py`, `bot/delivery.py` | Приём, очередь, повторы |
| `bot/dialog.py`, `bot/library_dialog.py` | Диалог и подтверждение удаления |
| `bot/search.py`, `bot/providers.py` | Опциональное определение названий и поиск |
| `bot/progress.py`, `bot/download_dashboard.py` | Прогноз и панель загрузок |
| `mac_agent/server.py`, `mac_agent/media.py` | Локальный API, диск, ограниченные операции |
| `mac_agent/rpc.py` | Аутентификация Transmission и handshake |
| `mac_agent/naming.py`, `bot/naming_worker.py` | Организация файлов и обновление Plex |

Ограничения: преимущественно русский UI, две роли (внутреннее историческое имя второй — `mother`), нет регистрации публичных пользователей, полной политики хранения, проверки авторских прав, гарантии доступности API и доказанного восстановления после закрытия крышки и отключения питания. При зависшем диске HTTP и RPC могут отвечать медленно. Необязательные изображения могут использовать неподдерживаемые методы Telegram и переходить к тексту. Тесты исходников не заменяют реальный сценарий новой установки.
