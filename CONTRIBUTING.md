# Contributing / Участие

Please report reproducible problems with synthetic examples. English and Russian are welcome. Keep both README files and parallel documentation in sync. Full English UI localization is a known contribution opportunity; do not label partial translation as complete.

Run `python3 -m unittest discover -s tests -q` and `python3 scripts/check_public_tree.py`. Add behavioral tests for changed access, deletion, retry or disk handling. Never test with another person's private account or media.

Do not submit credentials, cookies, personal conversations, database dumps, real server addresses, copyrighted media or unlicensed artwork. Redact logs locally before sharing. Security problems belong in private reporting, not public issues. Submit only work you have the right to license under MIT, preserve applicable attribution and declare third-party code origins. Contributions are licensed under this project's MIT license.

Можно писать по-русски. Присылайте воспроизводимые примеры с искусственными данными, обновляйте обе версии документации и запускайте тесты. Не публикуйте секреты, переписку, базы, адреса личных серверов, чужие файлы и изображения без разрешения. Уязвимости сообщайте приватно. Вклад должен принадлежать вам либо иметь совместимую лицензию с сохранением атрибуции; вклад распространяется по MIT.
